Purpose & Goals

Wofür diese Umgebung?

Das Lab dient als reale Testplattform – nah an Kundensituationen, fernab von produktiven Systemen.

🔬

Webex Feature-Evaluierung

Neue Webex Features, APIs und Beta-Funktionen werden im Lab getestet – insbesondere Hybrid Services (Calendar, Directory, Media) und Webex Cloud Calling.

🐍

Python, n8n & API Automation

Python-Skripte für Webex APIs: Bot-Frameworks, Webhook-Handler und Provisioning-Workflows. n8n für ereignisgesteuerte No-Code-Integrationen und Webex-Automatisierungen.

📞

Telefonie & Interop-Tests

SIP-Interoperabilitätstests zwischen Cisco IP Phones, 2N Intercom/Access Manager und Webex Cloud Calling. PSTN-Gateway-Szenarien und Trunk-Konfigurationen.

📡

Monitoring & Betrieb

Nagios-basiertes Monitoring der gesamten Infrastruktur. Passive Checks, Heartbeats und Alerting für alle Lab-Komponenten über cron-job.org.

🏗️

Infrastructure as Code

Ansible (Control Node auf RasPi) für reproduzierbare Deployments und Konfigurationsmanagement. Docker Stacks auf Synology NAS. Proxmox-Cluster als Virtualisierungsbasis.

📚

Dokumentation & PoC

Reproduzierbare Proof-of-Concept-Szenarien und technische Dokumentationen für Partner- und Kundenprojekte auf Basis realer Lab-Setups.

Infrastructure

Netzwerk­architektur

Die Infrastruktur gliedert sich in zwei Bereiche: eine öffentlich erreichbare Cloud-Infrastruktur sowie das private Home Lab.

☁ Public Infrastructure
  • VPS · Monitoring
    Nagios Core – aktives & passives Monitoring aller Lab-Komponenten. Heartbeat-Checks via cron-job.org. Eigener Hoster.
  • VPS · nginx / Reverse Proxy
    nginx als Reverse Proxy & Web-Server. Separater Hoster. WireGuard Tunnel zum Home-Lab-Gateway.
  • Netbox Cloud (Free)
    IPAM & DCIM als SaaS. Quelle für automatisch generierte Netzpläne. Keine Plugins verfügbar.
🏠 Home Lab
  • Unifi Gateway + Switch
    Ubiquiti Unifi als Netzwerk-Backbone. VLAN-Segmentierung für Lab, Heimnetz und Management. WireGuard Endpoint für VPS-Tunnel.
  • Proxmox Cluster
    Virtualisierungsplattform für VMs und LXC Container. Basis für Lab-Dienste im CLBSOLDEV-Segment.
  • Ansible Control Node · RasPi
    Raspberry Pi als dedizierten Ansible Control Node. Configuration Management, Ansible Vault für Secrets, Docker-Stack-Deployments.
  • Synology NAS · Docker Stacks
    Docker-basierte Dienste: n8n (Workflow-Automation + Webex-Integration), phpIPAM u.a. Deployed via Ansible.
  • Cisco Switch + IP Phones
    Managed Switch im Lab-Segment. Cisco IP Phones für Webex Calling & SIP-Tests. Nicht alle Lab-Hosts hängen direkt am Switch.
  • 2N Lab · Intercom & Access Manager
    2N IP Intercom und 2N Access Manager für Türkommunikation und Zugangssteuerung. Integration in Webex Cloud Calling.
🔒
WireGuard Tunnel
Zwischen dem VPS nginx und dem Unifi Gateway im Home Lab besteht ein permanenter WireGuard VPN-Tunnel. Dieser ermöglicht es, interne Lab-Dienste über den Reverse Proxy öffentlich erreichbar zu machen, ohne direkte Portfreigaben im Heimnetz.
